# Samadhan Gore - Portfolio

React + Vite + Tailwind portfolio with a code-themed animated hero and scroll-driven animation.

## Run
```bash
npm install
npm run dev      # development
npm run build    # production build in /dist
```

## Stack
- Canvas code-rain + drifting code snippets: animated hero background
- motion (Framer Motion): scroll reveals, timeline drawing, layout/filter animation, modal
- lenis: smooth inertial scrolling
- react-parallax-tilt: 3D tilt + glare on cards and portrait

## Edit your content
All data (skills, experience, education, projects) lives in `src/constants.js`.
Set a project's `github` or `webapp` to "#" and its button is hidden automatically.

## Colors
Defined in `tailwind.config.js` (void, violet, cyan, pink).
